# Project description
```
A simple React + TypeScript application that helps users save, organize, and manage their favorite links.
It provides an easy way to store links with a title, description, URL, and optional tags, and keeps them safe in your browser’s localStorage so they don’t disappear when you refresh.
```

# Installation and set-up
```bash
Clone the repository:
git clone https://github.com/ntombizodwantlahla53-code/MyTask2.git
cd MyTask2
```
# Run App
```bash
npm install
# or
yarn install

```
